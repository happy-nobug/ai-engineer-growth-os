# AI Engineer Growth OS

一个帮助初学者坚持学习 **大模型知识、LeetCode 和技术面试** 的网页学习工作台。

普通用户不需要下载代码、不需要安装软件，也不需要懂 GitHub。打开网站即可使用。

> **在线使用地址：** https://happy-nobug.github.io/ai-engineer-growth-os/。

## 30 秒开始使用

### 第一步：打开网站

点击上面的 GitHub Pages 在线地址，而不是 GitHub 代码仓库地址。

### 第二步：建立学习档案

第一次打开时，填写称呼、目标方向和每周可投入时间，然后点击 **保存并开始训练**。这些信息只保存在当前浏览器中。

### 第三步：完成今日任务

首页提供四类示范任务：

- **LLM 原理**：理解 Self-Attention
- **算法模式**：练习滑动窗口
- **工程实践**：改进 RAG 引用验证
- **复盘表达**：口述技术决策

完成一项后，点击任务左侧的圆形编号。页面会自动更新完成率和学习时间。

### 第四步：练习 LeetCode

向下滚动到 **算法训练 → 最小覆盖子串**：

1. 先在文本框写自己的思路、伪代码或代码。
2. 点击 **保存本次尝试** 保存草稿。
3. 卡住时点击右侧提示按钮。
4. 想重新独立完成时，点击 **重新独立挑战**。

请先思考再看提示。本工具的目标不是快速展示答案，而是帮助你形成独立解题能力。

## API Key 不是必需的

工具有两种使用方式。

### 模式 A：不连接 AI，免费直接用

什么都不用配置。你可以：

- 使用网页自带的五级提示
- 勾选每日任务
- 查看 12 周成长路线
- 保存当前解题草稿
- 生成示范面试清单

这是默认模式。没有 API Key，网页仍然可以正常使用。

### 模式 B：连接自己的 AI

如果你已经拥有某个模型服务的 API Key，可以让 AI 根据你的草稿给出个性化追问：

1. 点击页面右上角 **连接 AI 导师**。
2. 输入 API 服务地址。
3. 输入该服务要求的模型名称。
4. 输入自己的 API Key。
5. 点击 **测试并保存**。
6. 回到算法训练区，先写草稿，再点击 **让 AI 审阅当前思路**。

AI 导师被要求只指出一个关键问题或给一级提示，不直接提供完整答案。

注意事项：

- 仅支持 OpenAI-compatible 的 `/chat/completions` 接口。
- 模型服务必须允许浏览器跨域请求（CORS）。
- 连接失败时会自动退回内置提示，不影响继续学习。
- 不知道 API 地址或模型名称时，请查询所用模型服务商的文档。
- 不要在公共电脑输入长期有效的 API Key。

## 数据保存在哪里？

| 数据 | 保存位置 | 何时消失 |
| --- | --- | --- |
| 学习档案、任务进度 | 当前浏览器 `localStorage` | 清除该网站浏览数据时 |
| 解题草稿 | 当前浏览器 `localStorage` | 清除该网站浏览数据时 |
| API 地址、模型名称 | 当前浏览器 `localStorage` | 清除该网站浏览数据时 |
| API Key | 当前标签页 `sessionStorage` | 关闭标签页时自动清除 |

默认模式不会把学习内容发送给服务器。连接 AI 后，当前题目和解题草稿会发送给你配置的模型服务，因此不要输入隐私数据、公司代码或其他敏感信息。

## 当前版本能做什么？

这是一个第一版 MVP，用于验证学习流程和交互方式。

**已经可以使用：**

- 个人学习档案
- 每日训练任务与完成进度
- 12 周示范成长路线
- 一道 LeetCode 滑动窗口示范题
- 内置五级提示
- AI 个性化追问（需要用户自己的兼容 API）
- 解题草稿本地保存
- 模拟面试清单

**当前还不具备：**

- 完整 LeetCode 题库
- 自动运行和批改代码
- 完整的大模型课程内容
- 真正根据能力动态生成每日计划
- 间隔复习调度
- 登录账号和跨设备同步

它目前更适合作为**学习系统原型和个人训练看板**，还不是一套完整培训课程。

## 常见问题

### 打开 GitHub 后只看到代码，怎么使用？

你打开的是仓库页面。请点击 README 顶部提供的 GitHub Pages 在线地址。

### 一定要注册账号或购买 API 吗？

不需要。普通用户访问网页无需 GitHub 账号，内置提示模式也不需要 API。

### 为什么 API 测试失败？

常见原因包括：API 地址或模型名称错误、Key 无效、余额不足、网络限制，或者模型服务不允许浏览器跨域请求。失败后可继续使用内置模式。

### 换电脑后为什么没有学习记录？

目前数据只保存在当前浏览器，还没有账号和云同步。

## 开发者：本地运行

以下内容仅供想修改项目源码的人使用，普通用户可以忽略。

需要 Node.js 20 或更高版本：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 维护者：发布到 GitHub Pages

1. 将代码上传到仓库 `main` 分支。
2. 确认存在 `.github/workflows/deploy-pages.yml`。
3. 打开仓库级 **Settings → Pages**。
4. 将 Source 设置为 **GitHub Actions**。
5. 等待 `Deploy to GitHub Pages` Action 运行成功。
6. 将生成的在线网址填写到本 README 顶部。

项目使用相对资源路径，可以部署在任意名称的 GitHub Pages 项目仓库中。
